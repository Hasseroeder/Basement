...well, with a little asterisk, the resistance values you're seeing are your *internal* resistances.  
To convert them to usable percentages, we do this calculation:
  
`⇒ 0.8 (iPR) / (100 + iPR) = PR      `  
`⇒ 0.8 (iMR) / (100 + iMR) = MR      `  
  
`⇒ 0.8 ( 65) / (100 +  65) = 0.3152  ` ⇒ 31.5% PR :pr:  
`⇒ 0.8 (105) / (100 + 105) = 0.4098  ` ⇒ 41% MR :mr:
